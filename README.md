# 🚀 Estimate Management System

A modern web application built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS** components.  
This project is designed for managing and generating estimates in a clean, efficient, and user-friendly way.

---

## 🛠️ Tech Stack

-   ⚡ [Vite](https://vitejs.dev/) – Next-generation frontend tooling
-   ⚛️ [React](https://react.dev/) – Component-based UI library
-   🎨 [Tailwind CSS](https://tailwindcss.com/) – Utility-first CSS framework
-   📘 TypeScript – Strongly typed JavaScript

---

### Prerequisites

Make sure you have installed:

-   [Node.js](https://nodejs.org/) (v18+ recommended)
-   [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Install dependencies

```sh
npm install
```

Run development server
npm run dev
The app will be available at: http://localhost:5173/

📦 Build for production
npm run build

Preview production build:

npm run preview

🔹 Workflow

Dashboard Overview

 users see a dashboard with key metrics and summary values.

Estimate Module

Click on the Estimate module from the dashboard.

Estimate Details

Inside the module, users can view detailed estimates, including itemized costs, sections, and calculated totals.
